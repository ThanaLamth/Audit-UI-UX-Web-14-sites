## How to Use This Repo (for Claude)

Each site folder under `sites/<domain>/` contains:
- `audit-YYYY-MM-DD.md` — Full audit report with issues, recommendations, screenshots refs
- `issues.json` — Machine-readable issue list with priority (critical/high/medium/low), fix effort, and evidence
- `scorecard.json` — Per-category scores for programmatic access
- `screenshots/` — Desktop + mobile screenshots (01_home_top.png … 07_mobile.png)

To fix issues for a site, read `issues.json` for that site and prioritize `critical` then `high` items.

## Quick Fix Priority (All Sites)

Most common critical issues across the 13 sites:

1. **OG Image missing** — affects social CTR -40-60%
2. **NewsArticle JSON-LD missing** — blocks Google News rich results
3. **No llms.txt / AI-bot blocked** — blocks AI citation (GEO score impact)
4. **CSP header missing** — security risk
5. **No author pages / editorial policy** — E-E-A-T failure
